# 提示词打分系统

本地运行的提示词练习与打分工具。输入一条提示词，应用会调用你自己的大模型接口，按固定的 8 个维度打分，并给出问题诊断、改进版本和下一步建议。历史记录保存在浏览器里，不需要登录，也不需要数据库。

## 环境要求

- Node.js 18.17 或更高版本
- npm

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 [http://localhost:3000](http://localhost:3000)。

## 部署

应用本身没有后端业务接口。构建后用 Node.js 托管页面即可，评分请求由浏览器直接发到大模型服务。

```bash
npm install
npm run build
npm start
```

默认端口是 3000。需要换端口时：

```bash
npx next start -p 8080
```

把 API Key 填在页面设置里，或导入本地 `.env`。密钥只写入当前浏览器的 localStorage，不会进入本仓库。请确认你使用的模型服务允许浏览器跨域访问；若被拦截，页面会提示网络错误。

## 使用

1. 右上角可以在深色和浅色之间切换。默认是深色。
2. 点击「设置」。可以手工填写，也可以点「导入 .env」。仓库里的 `.env.example` 可复制为 `.env` 后再导入，空着的项不会覆盖已有值。
3. 填写或导入这三项后点「保存」：
   - **baseURL**：默认 `https://api.deepseek.com`。也可以改成其他 OpenAI 兼容接口，不要在末尾加多余的路径。
   - **apiKey**：对应服务的密钥。
   - **model**：默认 `deepseek-flash`。可以从列表选择，也可以直接输入其他模型名。
4. 可先点「测试连接」。成功说明地址和密钥可用。
5. 在左侧输入提示词。任务背景可以不填；展开后能选择工作汇报、课程博客等场景，也可以自己改。
6. 点「开始评分」，或在提示词框中按 `Ctrl+Enter`（macOS 为 `Cmd+Enter`）。
7. 右侧显示总分、等级、8 个维度、致命问题、跑偏预测、改进版提示词、改动说明和下一步。
8. 「历史记录」按时间查看以往评分，同一条提示词的迭代会缩进成一条链。可以删除单条或清空全部。

空提示词无法提交。未填写 API Key 时，评分会打开设置。单次请求超时时间为 60 秒。

## 评分标准

满分 100，分为 8 项：

| 维度 | 满分 |
| --- | --- |
| 目标与任务清晰度 | 15 |
| 背景与上下文 | 12 |
| 角色与受众 | 10 |
| 约束与边界 | 13 |
| 输出格式 | 12 |
| 示例与风格锚定 | 10 |
| 任务拆解与过程控制 | 13 |
| 精确性与无冲突 | 15 |

等级：90–100 为 S，80–89 为 A，70–79 为 B，60–69 为 C，40–59 为 D，0–39 为 F。

## 数据存在哪里

设置和历史都在本机浏览器的 localStorage 中，键名是 `prompt-gym:settings` 和 `prompt-gym:history`。清除站点数据后，这两项会一起消失。
